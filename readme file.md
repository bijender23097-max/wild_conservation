# WildGuard - Wildlife & Nature Conservation

A responsive web application developed to spread awareness about endangered wildlife species across India and promote practical conservation efforts.

---

## 📌 Objective
To educate individuals on wildlife preservation, highlight critically endangered and vulnerable species in India, and encourage community action through actionable tips and an interactive pledge system.

## ✨ Features
- **Responsive Navigation:** Clean navigation bar featuring a responsive mobile drawer menu.
- **Endangered Species Showcase:** Card grid highlighting key species (Bengal Tiger, Asian Elephant, Indian Rhinoceros, Snow Leopard) along with conservation statuses and facts.
- **Actionable Awareness:** Clear pointers on practical habits for environmental conservation.
- **Interactive Pledge Form:** Client-side form validation allowing visitors to pledge support for wildlife protection.

---

## 🛠️ Technologies Used
- **HTML5:** Semantic site structure
- **CSS3:** Flexbox layout, media queries for responsive mobile styling
- **JavaScript (ES6):** DOM manipulation for form validation and responsive navigation toggling
